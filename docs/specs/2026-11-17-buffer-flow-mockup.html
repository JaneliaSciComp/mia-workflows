Design notes
  • One noun. No "spec" rows and no separate list of specs: a buffer is its definition plus whatever has been built from it.
  • A buffer is known by its number; the name is a label. The id a script uses belongs to the version being served and is shown only then.
  • A row opens the buffer at the step it is on. The Status column says whether it waits for you or is working.
  • My guess: the Preparation tab goes away. A preparation started from a buffer shows inside that buffer's Prepare step; each dataset shows its own state on the Datasets tab.
